# ITIC Companion

## 📌 Présentation

**ITIC Companion** est une application développée dans le cadre de mon stage de première année.
Le projet a été conçu pour aider les étudiants à mieux gérer leur quotidien grâce à une plateforme centralisant plusieurs outils et fonctionnalités utiles.

L’objectif principal est de proposer une interface moderne, intuitive et accessible permettant d’améliorer l’organisation et l’expérience utilisateur des étudiants.

---

## 🚀 Fonctionnalités

* 📅 Gestion et organisation des tâches
* 👤 Interface utilisateur moderne et responsive
* 🔐 Système d’authentification
* 🌙 Mode sombre
* 📧 Gestion des informations utilisateur
* 📱 Design inspiré des applications modernes

## ⚙️ Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/Celemm/Companion.git
```

2. Ouvrir le projet avec Android Studio

3. Synchroniser les dépendances Gradle

4. Lancer l’application sur un émulateur ou un appareil Android
